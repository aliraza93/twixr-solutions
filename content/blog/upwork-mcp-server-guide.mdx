## Why an Upwork MCP server?

AI coding agents are great at writing proposals, summarizing jobs, and drafting client messages. They are **not** great at unsupervised hiring or payments. An [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server gives your agent structured tools for Upwork while you keep the high-risk actions behind explicit human approval.

This guide covers a practical setup for freelancers and agencies who want agents to help with Upwork workflows without handing over the keys.

## What MCP unlocks

With a well-scoped Upwork MCP server, agents can typically:

- Search and filter open jobs
- Summarize long job posts into decision-ready briefs
- Draft proposals from your profile and past wins
- Pull conversation history for context
- Flag contracts that need attention

> Tip: treat every write action (send proposal, send message, accept offer) as a **confirm-required** tool. Read tools can be freer; money and commitments should not be.

## Recommended architecture

1. **MCP server** exposes typed tools (search_jobs, get_job, draft_proposal, …).
2. **Your agent host** (Claude Desktop, Cursor, custom) connects over stdio or HTTP.
3. **Auth** uses OAuth / API credentials stored in a secrets manager - never in the prompt.
4. **Policy layer** blocks tools that hire, pay, or change billing without a human.

```bash
# Example: run a local MCP process (illustrative)
npx upwork-mcp --config ./upwork.mcp.json
```

## Safety checklist

- Rotate API tokens on a schedule
- Scope tokens to the minimum Upwork permissions
- Log every tool call with actor + timestamp
- Require dual confirmation for payment-related tools
- Keep a kill switch to disable the MCP server instantly

## Getting started with Claude or Cursor

1. Install the MCP package and authenticate.
2. Register the server in your agent config.
3. Start with **read-only** tools for a week.
4. Enable draft-only write tools, then review before send.
5. Only then consider send-with-confirmation flows.

## FAQ

**Can an AI agent hire or pay someone on its own?**
No. A responsible MCP setup keeps hire and payment tools disabled or gated behind human confirmation. Agents should draft; humans should commit.

**Which AI tools does it work with?**
Any MCP-compatible host - Claude Desktop, Cursor, and custom agent runtimes that speak MCP. The Upwork tools stay the same; only the host changes.

**Is my Upwork account safe?**
Safety depends on credential hygiene and tool policy. Use short-lived tokens, least privilege, and never paste secrets into chat history.

**Do I still need to write proposals myself?**
You can let the agent draft them, then edit tone and specifics. Most Top Rated freelancers still review every send - that is the point of the confirm step.
