# Content pillars & rotation

## Daily rotation (7 posts/week)

Each day owns a job. Sub-topic rotates via topic-bank.md + post-log.md so no
two runs repeat.

- **Mon - Build (credibility):** a genuinely useful technical post. Rotate
  across Laravel, NestJS, AWS/DevOps, Technical SEO, API design, architecture,
  or a code-tip card.
- **Wed - Timely (reach):** AI & industry news, a new framework/tool release,
  a hot take reacting to something current, OR a **regional Big-Tech / IT-policy
  event** (see below). This is the engagement slot. MUST be verified against a
  real source that run (see rules).
- **Fri - Business (clients):** freelancing / Upwork / Fiverr tip, positioning
  (tech-as-outcome), or an anonymized client story. This is the slot that
  attracts founders and CTOs.

## Hook playbook (apply to EVERY post)

1. **Problem-first.** Line 1 names a pain the reader already feels, in their
   words. Make them think "that's me."
2. **Short lines, heavy white space.** One idea per line.
3. **Sell the outcome, not the stack.** Tech is proof, lower down.
4. **Numbers beat adjectives.** "900 queries to 6" beats "much faster".
5. **One easy question as the CTA.** Something answerable in one line.

Hook templates that work:
- Costly symptom: "One deploy took a client's SaaS offline for 26 minutes."
- Misdiagnosis: "Your SEO agency wants more content. Your problem is a 4s load."
- Contrarian: "Most SaaS startups don't need microservices."
- Blunt callout: "Your Upwork profile is a skills list. That's why it's skipped."
- Timely take: "Everyone's posting about [new model]. Here's what it changes for
  people who actually ship."
- Regional news, deflate-the-hype: "[Big Tech] just opened its first office in
  [city]. Great headline. It's still not a cloud region."

Always generate 2 alternate hooks per post.

## Rules

- New post every run: read post-log.md, exclude everything in it, append after.
- Reach for the 2nd or 3rd idea in a pillar, not the obvious textbook one.
- News/AI: verify via web search THIS run. Never invent a model, feature,
  version, benchmark, price, or date. Name the source. Can't verify → use an
  evergreen topic instead.
- **Timely-slot scan (do every Wed run):** before defaulting to a model/tool
  release, web-search for a current, verifiable **Pakistan / regional Big-Tech
  or IT-policy** story (Big-Tech offices, cloud regions, data centres, IT-export
  moves, major partnerships). If a strong one exists, prefer it - it out-reaches
  generic dev news for this audience. If not, fall back to AI/industry news.
- On regional-news posts, "challenges" = the builder's honest open questions
  (cloud region / latency / data-residency, payment rails, sales vs engineering
  presence, talent retention). Frame as opinion/questions, never as invented
  facts.
- Watermark all images with https://twixrsolutions.com - **but only Ali's own graphics.**
  Never watermark or redistribute a third-party press/news photo; for a
  news-reaction post, point Ali to the source to attach the official photo
  himself, or use an openly-licensed/Unsplash image with proper credit.
